# 写作知识库 — 详细业务 PRD

> 知识库是独立模块，同时被 `ai-writing` 内嵌。目标：把课程「拆书 / 猜书 / 分析报告 / 桥段素材 / 换元」产品化。

---

## 1. 目标

用户上传番茄 / 晋江 / 漫剧剧本等文本后，系统自动：

1. 分类打标签
2. 生成拆书报告（九格参数模板 + 课程各类报告）
3. 抽取桥段 / 套路 / 人物 / 情节点
4. 构建人物关系知识图谱
5. 支持自然语言检索（「哪些书出现过某某桥段」）
6. 支持热点榜单摘要（合规）
7. 一键送到写作台做换元 / 仿写

---

## 2. 文档生命周期

```
上传 → 解析清洗 → 自动分类打标 → 切片入库（向量+全文）
→ 分析流水线（可异步）→ 报告/图谱/桥段库
→ 用户检索 / AI 助手问答 → 推送到创作项目
```

| status | uploading / parsing / indexed / analyzing / ready / failed |
| word_count | |
| storage_uri | MinIO |
| hash | 去重 |
| visibility | private / workspace |
| analysis_report_ids | |
| graph_id | |

### 2.2 CRUD

- 上传（单文件 / 批量）、重命名、移动文件夹、删除、重新分析
- 文件夹与标签双导航
- 去重提示（相同 hash）

---

## 3. 自动分类与标签

### 3.1 标签体系（可扩展）

- 渠道：男频 / 女频
- 体裁：短篇 / 长篇 / 短剧 / 漫剧剧本
- 题材：脑洞异能、末世、系统、追妻火葬场、甜宠…（对齐课程热门列表）
- 套路：装逼打脸、身份反转、重生复仇…
- 情绪主调：爽 / 虐 / 甜 / 悬疑…
- 平台对标：番茄、起点、晋江…
- 质量：适合仿写 / 适合换元 / 仅素材

### 3.2 规则

- 模型打标 + 规则词典校正
- 用户可改标；改标反馈进记忆（提升后续准确率）

---

## 4. 分析报告类型

| 报告 | 内容来源 | 用途 |
|------|----------|------|
| 拆书参数报告 | 2 课参数模板 | 换元/仿写输入 |
| 单元故事拆解 | 大中小层级 + 七步法 | IP 改编减法 |
| 情绪曲线报告 | -10～+10 量化 | 节奏对齐 |
| 核心梗提取 | 梗 vs 情节卡 | 选题 |
| 人设关系报告 | 10 课清单 | 图谱 |
| 爽点/虐点分布 | 6/7/11 课 | 仿写爽点 |
| 期待感/钩子报告 | 4 课 | 商业化检查 |
| 文风要素报告 | 提示词技巧：抽文风 | 仿风格不仿内容 |
| 风险红线报告 | 15/17 课 | 投稿前 |
| 对标差距报告 | 与爆款结构对比 | 改稿方向 |

报告均：Markdown + 结构化 JSON 双存；可导出；可「应用到项目」。

## 5. 桥段 / 套路素材库

### 5.1 实体 `TropeClip`

- 名称、摘要、完整片段引用（带原文定位）
- 标签、情绪峰值、适用题材
- 可换元提示（建议置换哪些源）
- 来源文档

### 5.2 能力

- 浏览 / 搜索 / 收藏
- 「用此桥段生成变体」（调用换元或桥段练习 Agent）
- 从报告一键入库

---

## 6. 知识图谱

### 6.1 目标

详细展示人物与人物关系、势力、事件因果，帮助理解规则与冲突结构。

### 6.2 节点

- Character、Faction、Location、Item/MacGuffin、Event、Trope、EmotionBeat

### 6.3 边

- 关系类型：亲属 / 爱恋 / 对立 / 主仆 / 隐瞒 / 债务 / 师徒…
- 属性：强度、公开/秘密、时间范围、关键情节引用

### 6.4 UI

- 力导向图 + 右侧详情（密集字段）
- 过滤：只看对立、只看感情线
- 点击边跳转原文定位
- 导出 JSON / PNG

### 6.5 技术

- MVP：SQLite JSON + 前端可视化（react-force-graph 等）
- 后期可选 Neo4j（角色关系极复杂工作室场景）

---

## 7. AI 搜索与助手

### 7.1 查询类型

1. 语义搜片段：「退婚打脸桥段」
2. 结构化：「系统文 + 末世 + 开篇强冲突」
3. 跨书统计：「哪些书用过女扮男装」
4. 分析问答：「这本的情绪曲线问题在哪」

### 7.2 检索栈

- Milvus：向量
- SQLite FTS5 / 或 Tantivy：关键词
- Grep 工具：Agent 精确找字符串（人设名、专有名词）
- 混合重排后返回答案 + 引用

### 7.3 DeepSeek 等联网搜索（可选）

- 用于公开资料 / 题材趋势解释
- 与本地库结果分区展示，标明来源

---

## 8. 热点（合规）

### 8.1 范围

- 仅公开榜单：书名、排名、标签、简介级摘要（若页面公开）
- **禁止**整本盗爬、付费章抓取、绕过登录墙

### 8.2 功能

- 热点列表、题材波动简单统计
- 「根据热点生成核心梗方向」按钮 → 写作台
- 来源与抓取时间展示；失败重试；robots/服务条款配置开关

## 10. MVP 验收

1. 上传一篇 TXT → 自动标签 → 拆书参数报告可看
2. 搜索桥段能返回带来源的片段
3. 人物关系图至少含角色节点与主要关系边
4. 一键推送到漫剧/短篇项目并进入对应 Stage
5. 删除文档同步清向量与对象存储
