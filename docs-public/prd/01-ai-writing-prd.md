# AI 商业化写作 — 详细业务 PRD

> 目标：业务拆到可直接生成 API / Agent / 页面的粒度。

---

## 0. 产品原则（来自课程，必须产品化）

| 原则 | 产品落点 |
|------|----------|
| AI 单次优质输出约 2000–3000 字 | 生成参数默认按「情节点数」控长；批量按集/章队列 |
| 工作流：灵感→总纲→章纲→细纲→初稿→修改 | 创作台 Stage 条；未完成前置 Stage 不可跳过（可强制跳过需二次确认） |
| 格式开关：短篇/长篇/短剧/漫剧 | `project.format` 决定 Agent 图与 Prompt 包 |
| 规则+指令分离 | Prompt 模板：`locked_system` + `editable_instruction` + `example_slots` |
| 核心梗可生成几十～上百再筛 | 批量生成 + 收藏夹 + 评分维度 |
| 人工主导，AI 取 30%–50% 可用 | 候选卡「采纳 / 丢弃 / 再生成 / 微调」 |
| 逻辑 AI 不可靠 | LogicGate 只做启发式提醒；人工确认才过 |
| 去 AI 味 + 手动精修 | DeAI 味 Agent + 校稿 Checklist |
| 商业化要有钩子 | 每集/章尾钩子门禁 |

## 1. 首页

### 1.1 目标

介绍产品能力，用题材入口直接跳进对应创作台。

### 1.2 模块

1. **品牌与定位**：产品名 + 一句话（AI 同事型商业写作台）
2. **能力摘要**：工作流、多智能体、知识库、去 AI 味、断点续写（不堆统计卡片）

   - 短剧创作台
   - 短篇网文
   - 女频中长篇
   - IP 改编
4. **次行动**：打开项目列表 / Prompt 管理 / 知识库
5. **最近项目**（若已登录）：密集列表，点入续写

### 1.3 交互

- CTA 点击 → 若无项目：引导「新建项目」并预填 `format`
- 若有草稿项目：弹「继续上次 / 新建」

## 2. 项目管理（CRUD + 续写）

### 2.1 实体 `Project`

| 字段 | 类型 | 说明 |
|------|------|------|
| id | uuid | |
| user_id | uuid | |
| title | string | 可空，未定名前用临时名 |
| format | enum | `manju` / `duanju` / `short_novel` / `male_long` / `female_long` / `ip_adapt` |
| genre_tags | string[] | 男频/女频 + 题材标签 |
| market | enum | `cn` / `overseas` / `both` |
| stage | enum | 见 Stage 机 |
| status | enum | `active` / `paused` / `archived` / `submitted` |
| progress | json | 各 artifact 完成度 |
| cover_meta | json | 一句话简介、对标作品等 |
| budget_tokens | int? | 项目级预算 |
| created_at / updated_at | datetime | |
| last_opened_at | datetime | 续写排序 |

### 2.2 列表页需求

- 密集表格式：标题、格式、当前 Stage、更新时间、Token 消耗、状态
- 筛选：格式 / 状态 / 题材 / 关键词
- 操作：打开、重命名、归档、复制项目（复制设定与 Prompt 绑定，不复制全文可选）、删除（二次确认）
- 点击行 → 进入该格式创作台，定位到当前 Stage

### 2.3 新建项目向导

1. 选格式（必选）
2. 选男频/女频 + 主攻题材（影响 Prompt 删减）
3. 选起点：空白 / 从知识库导入拆书 / 从已有核心梗 / 从 IP 原文
4. 绑定默认 Prompt 包（可改）
5. 创建并进入创作台

### 2.4 项目内 Artifact 树

```
Project
├── CoreHooks[]          # 核心梗候选 + 已采纳
├── SwapPlans[]          # 换元方案
├── Characters[]         # 人设 / 小传
├── WorldBible           # 世界观 / 金手指
├── Outline
│   ├── MasterOutline    # 总纲 / 故事梗概
│   ├── VolumeOutlines[] # 卷纲（长篇）
│   ├── ChapterOutlines[]# 章纲
│   ├── BeatSheets[]     # 细纲 / 情节点
│   └── EpisodeOutlines[]# 分集大纲（漫剧/短剧）
├── Manuscripts[]        # 正文（章/集）
├── QCReports[]          # 质检报告
├── Emotions[]           # 情绪曲线数据
└── MemoryLinks[]        # 关联记忆文件
```

所有 Artifact：**版本化**（每次生成/手改为新 version，可回滚）。

## 3. Stage 状态机（按格式）

### 3.1 漫剧 `manju`（九格金牌路径 · 考拉顺序）

```
S0_SETUP → S1_HOOK_BATCH → S2_HOOK_CRITIC → S2_HOOK_SELECT（人工）
→ S2_LOGLINE_100（100字测试·人工）→ S2_COOL_BATCH（爽虐点）
→ S3_BIO → S3_BIO_ACK（人工）
→ S4_EP10_OUTLINE → S4_OUTLINE_ACK（人工）
→ S5_EP_BODY_BATCH（默认前3集·串行+Bible注入·衰减硬停）
→ S6_QA → S7_STORYBOARD → S8_DIALOGUE
→ S9_DE_AI → S10_HUMAN_QC（LogicAck·人工）
→ S11_EXTEND ↻ S5  |  S11_PITCH（四件套）→ S11_DONE
```

硬规则：人设先于大纲；大纲未人工确认不得写正文；字数相对上集跌破 70% 或低于 800 立刻停并进 QA。

对应课程：`ai漫剧写作流程和方法.md`、11/16/17 课、施大手册、考拉实操流。

### 3.2 短篇 `short_novel`（换元主流程）

```
S0_SETUP → S1_DISSECT（拆书）→ S2_SWAP（一度/二度）
→ S3_SYNOPSIS → S4_CHAPTER_OUTLINE → S5_BEAT
→ S6_BODY_CHAPTER → S7_POLISH → S8_QC → S9_DONE
```

对应：2/3/8/9/10 课 + 换元法。

### 3.3 短剧 `duanju`

```
S0 → 选题/期待冲突 → 人设 → 单元故事结构
→ 分场/分集大纲 → 正文 → 钩子检查 → 去AI味 → 人工
```

对应：4/5/6/7 + 查理课程可后续挂载。

### 3.4 男频中长篇 `male_long`

```
刷榜选题+开篇钩 → 金手指设定 → 人设 → 卷纲升级循环
→ 章纲 → 细纲 → 分章正文 → 爽点密度 → 雷区+去AI味
```

对应：男频升级/打脸/金手指课 + `knowledge/16-male-long/`。

### 3.5 女频中长篇 `female_long`

```
选题 → 人设 → 架构/卷纲 → 章纲 → 细纲
→ 分章正文 → 节奏/情绪门禁 → 雷区检查 → 付费点适配
```

对应：14/15 课。

### 3.6 IP 改编 `ip_adapt`

```
选IP评估 → 拆单元故事 → 情绪曲线量化
→ 压缩重构 → 单集节奏 → 卡点 → 剧本输出
```

对应：13 课。

### 3.7 Stage 规则

- 默认禁止跳 Stage；「高级用户：强制跳过」需确认并写审计日志
- 每 Stage 有 **Done Contract**
- `last_opened` 恢复：打开项目时滚到未完成 Stage + 未读 Agent 消息

## 4. 创作台 UI（密集信息）

### 4.1 布局

```
┌────────┬──────────────────────────────┬────────────┐
│ Stage  │ 主工作区（当前 Artifact 编辑） │ 右侧面板   │
│ 导航   │ 字体偏小、信息密度高          │ Agent 运行 │
│ 树形   │ 多栏对照（原文/生成/差异）    │ 候选列表   │
│ Artifact│ 勾选清单 / 表格式大纲         │ 记忆/知识库│
└────────┴──────────────────────────────┴────────────┘
```

### 4.2 UI 规范（产品级）

- 字号默认偏小（12–13px 正文区可配），列表行高紧凑
- 少卡片；用表格、树、分割线组织
- 一次生成多次：候选以**可勾选列表**展示，支持对比 2–3 个
- 流式输出可见；可中止；可「保留半成品」
- 快捷操作：再生成 N 次、仅改指令再跑、采纳并进入下一步

### 4.3 对照模式

- 拆书原文 | 拆书参数
- 原作元素 | 换元映射
- 大纲 | 正文
- AI 稿 | 去 AI 味稿 | 人工稿

## 5. 分业务功能详解

### 5.1 核心梗（Hook）— 最高优先

**需求**

- 输入：格式、男频/女频、题材删减后的 Prompt、市场（国内/海外）、对标、用户偏好
- 输出字段（漫剧标准，来自手册）：
  - `title_hook`（标题式一句话）
  - `core_hook`（核心梗正文）
  - `tags`
  - `motivation`（复仇线/事业线等）
  - `crisis`
  - `opening_structure`
  - `opening_beats`
- 默认一次生成 **10**；可设 20/50/100（队列分批，避免上下文爆炸）
- 用户可对每条：评分（代入感/爽感/差异化/动机清晰/主线清晰）、收藏、备注、再生成变体
- **采纳 1 条**后进入下一 Stage；未采纳可并行保留多个备选

**门禁**

- 题材未删减（男女频混杂）→ 警告
- 缺动机或开篇结构 → 不可「强采纳」仅可「草稿采纳」
- 红线题材 → 拦截或高亮风险

**多次生成**

- 必须支持；每次写入 `generation_batch_id`
- 可基于已选梗「微创新再来 10 个」

### 5.2 拆书 / 参数（Dissect）

**输出结构（课程参数模板）**

- 基本信息（书名、类型、字数、对标平台）
- 故事设定（世界观、金手指）
- 故事脉络
- 情绪曲线（-10～+10 可量化）
- 人物关系
- 起承转合 / 单元故事层级（大/中/小）
- 七步法：目标-阻碍-行动-结果-意外-转折-结局
- 核心梗 vs 情节卡区分结果
- 节奏量化：章数、每章字数、每章情节点、点均字数

**交互**

- 上传 TXT/MD 或从知识库选择
- 支持合并猜 / 分章猜（课程「猜书」能力产品化）
- 产出报告可一键「送去换元」或「送去仿写」

### 5.3 换元法（Swap）

**一度置换**：换背景、人物、道具（事件与结构尽量保留）  
**二度置换**：核心事件替换 + 其他元素联动

**六大故事源**：事件、结构、主体、背景、人物、道具

**流程**

1. 故事诊断（拆六源）
2. 方案匹配（出 3 个方案，用户选）
3. 框架重构（梗概）
4. 改章纲 → 改细纲（批量）
5. 逻辑校验
6. 迭代

**输出**

- 换元思路（新旧映射表）
- 新梗概（约 150 字）
- 关键情节点 8–12
- 人物画像
- 标志场景 3–5
- 延伸方向

### 5.4 人设（Character）

**清单字段（10 课）**

- 大五人格底色
- 欲望（为什么非要不可）
- 恐惧（阴影）
- 终极秘密
- 背景 / 价值观 / 行为模式 / 口头禅
- 与其他角色关系

**门禁：灵魂拷问三问**（生成情节后校验是否符合人设）

### 5.5 大纲体系

| 类型 | 用途 | 注意 |
|------|------|------|
| 故事梗概 / 总纲 | 主线一页纸 | 漫剧忌「起承转合平均分配」 |
| 卷纲 | 长篇 | |
| 章纲 | 短篇/长篇 | |
| 细纲 / 情节点 | 控 AI 篇幅 | 用点数控长 |
| 分集大纲 | 漫剧/短剧前十集等 | 表格↔文字双视图 |
| 爽点剧情扩展 | 核心梗→10 个套路爽点 | 必须附核心梗，否则拒跑 |

**扩展后续大纲**：输入 = 核心梗 + 已有分集大纲 + 参考案例

### 5.6 正文生成

**漫剧**

- 格式：分镜画面 + 台词；禁小说化形容词堆砌
- 单集约 800–1200 字；≤3 场景；台词含旁白 ≤500 字
- 10 集一轮批量队列
- 集尾必须留钩子（门禁）

**短篇/长篇**

- 按章；每章情节点约束
- Show don't tell；禁用直述情绪套话（可配置）

**批量**

- 队列：待生成 / 生成中 / 待审 / 已采纳
- 失败重试；单集失败不阻断整批
- Token 预估与预算熔断

### 5.7 AI 校正

- 总体问题（常出现在第 3 集后）：字数不足、场景过多、台词不推动情节
- 单集优化：指定集号 + 集尾悬念
- 字数衰减检测：后集明显变短自动报警

### 5.8 去 AI 味

- 使用课程 `去ai味儿.md` / V3.8 规则 Skill
- **禁止改主题/走向/结局；禁止删关键场景人物对话**
- 短句为主（≤20 字倾向）、禁套路比喻等
- 产出：润色稿 + 自查清单勾选状态
- 后接人工校稿（逻辑 / AI 表述漏网 / 镜头 / 人物语言 / 伏笔钩子）

### 5.9 期待感 / 冲突 / 情绪 / 爽点

作为 **Gate Agent + 专项改写 Agent**，可在大纲或正文 Stage 调用：

- 期待感架构（抛钩/收钩）
- 矛盾冲突升级路径
- 情绪曲线对齐对标
- 装逼打脸四前提 + 三阶打脸
- 代入感五问自检

### 5.10 IP 改编专项

- 选书四指标评分
- 压缩比例建议
- 单元故事拆解 → 情绪量化 → 搭积木重构
- 单集节奏与卡点（付费点）
- 导语公式

### 5.11 女频长篇专项

- 选题 / 人设 / 架构
- 节奏配比与缓冲剧情
- 四大情绪渲染
- 雷区（政策+创作）检查
- 变现适配（签约/付费/改编）提示

## 6. Prompt 管理

### 6.1 模板结构

```yaml
id: manju.core_hook.v1
name: 漫剧核心梗
format: [manju]
stage: S1_HOOK_BATCH
locked_system: |   # 用户不可编辑（或需「解锁」权限）
  ...角色与硬约束...
editable_instruction: |  # 用户可改
  题材偏好、数量、语气...
example_slots:           # 示例区，可替换
  - ...
variables:               # 结构化变量，表单编辑，防改坏
  - key: genre_list
    type: tag_list
output_schema: CoreHookBatch
gates: [GenreTrimGate, RedlineGate]
```

### 6.2 规则

- 默认展示：表单化变量 + 可编辑指令预览
- 「高级：编辑全文」→ 警告；校验必须保留的锚点句（checksum / required_phrases）
- 版本：官方包 / 用户 fork；可对比 diff；可回滚
- 按格式打包：`PromptPack(manju)` 含全流程模板

### 6.3 内置包来源

- 施大《AI漫剧实操手册（提示词）》
- 换元法 3.0
- 去 AI 味 V3.8
- 课程中可还原的结构模板（标注「非课堂逐字」）

## 9. AI 同事（Grok-like）

### 9.1 定位

可主动找活、可组队的写作同事，不是聊天玩具。

### 9.2 能力

1. **主动建议**：根据项目 Stage 缺口提出下一步（例：前十集大纲缺钩子）
2. **找活干**：扫描知识库新上传未拆书；扫描过期热点；扫描未去 AI 味正文
3. **组队协作**：
   - Synthesis：10 个核心梗并行 + 市场评估汇总
   - Ordered：必须按 Stage 顺序
   - Union：人设组与世界观组并行（无文件冲突时）
4. **会话**：可 @某个 Agent；可批准/拒绝其计划

### 9.3 权限

- 默认只读扫描 + 提议
- 写操作需用户一键批准（可对「低风险再生成」设自动批准）

## 12. 验收标准（MVP 漫剧）

1. 能新建漫剧项目并走完 S0–S8 产出至少 3 集可用正文（含去 AI 味稿）
2. 核心梗一次可生成 ≥10 条并收藏/采纳
3. 项目列表可续写到断点
4. Prompt 可变区可改且锁定区改坏会被拦截
5. Token 页面能看到本次核心梗生成消耗
6. 门禁：缺钩子的集不可标「完成」
7. 前端密集、可对照大纲与正文
