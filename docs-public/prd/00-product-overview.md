# 产品总览 PRD

> **定稿**：本地单用户写作助手；多租户 / 账号体系 **已回退（BACKLOG phase 021），本期不做**。  
> Agent = Node 自研 tool loop（唯一执行引擎）。详见 `docs/architecture/00-tech-stack.md`。

## 1. 一句话定位

面向商业化写手（网文 / 短篇 / 短剧 / 漫剧）的 **AI 同事型写作工作台**：把九格训练营「可复用工作流」做成可点选、可续写、可质检的多智能体系统，并配写作知识库提供拆书、桥段、换元素材与分析报告。

## 2. 目标用户

| 角色 | 诉求 |
|------|------|
| 新人写手 | 按流程仿写 / 换元，快速产出可投稿短篇或漫剧前十集 |
| 兼职商业写手 | 批量核心梗、分集批量写、去 AI 味、项目管理与续写 |
| 资深编剧 | Prompt 微调、门禁自定义、知识库拆书与图谱、多智能体协作 |
| 工作室编辑 | 选题评估、质检报告、题材红线、投稿规范检查 |

## 3. 非目标（本期不做）

- 不替代平台投稿账号体系（番茄 / 晋江登录发文）
- 不做自动支付结算 / 稿费对账
- 不爬取全文版权内容做商用分发（热点仅公开榜单摘要级）
- 不做视频/分镜渲染成片（只到剧本分镜文本）
- 不做「一键完稿无人审」承诺（产品明确：AI 80% + 人工 20%）

## 4. 成功指标

| 指标 | 说明 |
|------|------|
| 流程完成率 | 新建项目走到「首批正文 + 质检」的比例 |
| 续写成功率 | 从项目列表点入后 7 天内继续生产的比例 |
| 候选采纳率 | 核心梗 / 大纲多次生成中用户采纳次数 |
| 门禁拦截有效率 | 被 Gate 打回后二次通过且用户未大幅手改的比例 |
| Token 可控 | 用户能看清每步消耗并设置预算 |

## 7. 版本规划

### MVP（V0.1）

- 漫剧创作台全流程：核心梗（多次）→ 100字测试 → 人设小传 → 前十集大纲（人工闸）→ 分集正文（衰减硬停）→ 校正 → 去小说化 → 去 AI 味 → 人工校稿清单 → 投稿四件套
- 项目管理 CRUD + 断点续写
- Prompt 管理（可变区 / 锁定区）
- 模型 API Key（DeepSeek / MiniMax / 任意 OpenAI-compatible）
- Tokens 计量基础页
- 知识库：上传 TXT/MD、自动标签、拆书报告（参数模板）、语义搜索

### V0.2

- 短篇换元工作流、期待感/冲突/情绪节奏门禁
- 短剧 / IP 改编流水线
- 知识图谱人物关系可视化
- AI 同事主动任务建议 + 组队并行生成

### V0.3

- 男频/女频中长篇卷纲/章纲批量
- 公开榜单热点摘要（合规）
- 桌面端 Tauri 打包（macOS / Windows）
- 记忆管理系统完整 UI（热/温/冷、USER.md / PROJECT.md）

## 8. 合规与风险

- 用户上传内容默认私有；知识库入库需用户确认授权范围
- 热点采集仅公开页面元数据/榜单摘要，禁止整本盗爬
- 题材红线 Gate：政策敏感、违规擦边 → 警告或拦截（可配置严格度）
- Prompt / 记忆隔离：按 user_id + project_id
